# SopromatLab

SopromatLab - учебное веб-приложение для расчета балок и изучения сопротивления материалов. Пользователь задает схему балки и нагрузки, после чего приложение рассчитывает реакции опор, поперечные силы, изгибающие моменты, углы поворота и прогибы.

Автор: Екатерина Водопьянова.

## Возможности

- расчет консольной, шарнирно-опертой балки и балки с вылетом;
- сосредоточенные силы, равномерные и треугольные распределенные нагрузки, сосредоточенные моменты;
- построение схемы балки, эпюр Q(x), M(x) и деформированной оси;
- вывод реакций опор и пошагового решения;
- готовые расчетные сценарии и тренажер со случайными задачами;
- теоретический справочник по построению эпюр;
- экспорт результатов в PDF и ссылка на сохраненную конфигурацию;
- чат-консультант, который получает параметры текущей балки и результаты расчета.

Основной расчет выполняется во фронтенде. Бэкенд нужен только для чата и не получает API-ключ от браузера.

## Стек

Фронтенд: React, TypeScript, Vite, Chakra UI, D3, Framer Motion, html2canvas и jsPDF.

Бэкенд: Node.js, Express, TypeScript и OpenAI-совместимый API.

Развертывание: Docker Compose, многоэтапная сборка фронтенда и Nginx.

## Запуск через Docker

Понадобятся Docker Desktop и ключ OpenAI-совместимого API.

1. Создайте локальный файл с настройками бэкенда:

```powershell
Copy-Item backend/.env.example backend/.env
```

2. Откройте `backend/.env` и укажите `OPENAI_API_KEY`. При необходимости измените `OPENAI_BASE_URL` и `OPENAI_MODEL`.

3. Соберите и запустите контейнеры:

```powershell
docker compose up --build
```

4. Откройте `http://localhost`.

Расчетная часть работает без ключа. Без ключа будет недоступен только чат-консультант.

## Локальный запуск

Понадобится Node.js 20.19 или новее. Команды выполняются в двух терминалах.

Сначала запустите бэкенд:

```powershell
cd backend
Copy-Item .env.example .env
# Укажите OPENAI_API_KEY в файле .env
npm ci
npm run dev
```

Затем запустите фронтенд:

```powershell
cd frontend
npm ci
npm run dev
```

Приложение будет доступно по адресу `http://127.0.0.1:5173`. Vite перенаправляет запросы `/api` на бэкенд по адресу `http://127.0.0.1:3001`.

## Переменные окружения

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `OPENAI_API_KEY` | да, для чата | ключ основного провайдера |
| `OPENAI_BASE_URL` | нет | адрес OpenAI-совместимого API |
| `OPENAI_MODEL` | нет | модель основного провайдера |
| `PORT` | нет | порт бэкенда, по умолчанию 3001 |
| `FALLBACK_OPENAI_API_KEY` | нет | ключ резервного провайдера |
| `FALLBACK_OPENAI_BASE_URL` | нет | адрес резервного провайдера |
| `FALLBACK_OPENAI_MODEL` | нет | модель резервного провайдера |

Настоящие ключи нельзя добавлять в Git. Файл `backend/.env` исключен через `.gitignore`.

## Как выполняется расчет

Расчетная модель разбивает балку на 500 точек. Реакции опор определяются из уравнений статического равновесия и принципа суперпозиции. Для каждой точки вычисляются Q(x) и M(x), а угол поворота и прогиб находятся численным интегрированием методом трапеций с учетом граничных условий.

В модели используется постоянная изгибная жесткость `D = E * I`, где `E = 2.1e11 Па`, `I = 8.356e-6 м^4`. Значения заданы в `frontend/src/features/calculation/lib/constants.ts`.

## Ограничения

- приложение предназначено для учебных расчетов, а не для проектирования реальных конструкций;
- материал и момент инерции сечения пока заданы константами;
- расчет основан на линейной модели малых деформаций;
- доступны только плоские статические задачи для трех типов балок;
- точность прогиба зависит от дискретизации на 500 точек;
- чат требует доступа к внешнему API и корректного ключа провайдера.
